KNOWN ASSET LIMITATION
The working package copy still does not contain the eight user-supplied process images / festival logos and three local pillar MP4 files listed in ASSET-AUDIT.txt. The HTML references are preserved and image fallbacks remain, but those files must be present in the deployment folder for the real images and local videos to appear. The three local videos are intentionally loaded and played immediately on normal-motion, non-data-saving visits, as requested; this makes their actual file size and encoding an important part of real-world loading performance.

EXTERNAL SERVICES / LIVE-ONLY CHECKS
- Google Fonts is used for the approved brand typefaces.
- YouTube supplies the hero and hardware embeds; YouTube branding/overlays cannot be completely suppressed by embed parameters.
- FormSubmit handles contact-form delivery and requires successful activation/testing on the live domain.
- CounterAPI supplies the shared public visit counter; availability depends on that third party.
- This static build cannot verify actual search indexing, Google/Bing rankings, live form delivery, live counter increments, HTTP range support for MP4s, or field Core Web Vitals.

DEPLOYMENT VERIFICATION
1. Upload all package files to the HTTPS host, preserving exact relative paths and case-sensitive filenames.
2. Add the assets listed in ASSET-AUDIT.txt if they are not already on the host.
3. Confirm https://eyebyte.tv/ is the preferred canonical host and redirects variants consistently.
4. Verify the domain in Google Search Console and Bing Webmaster Tools; submit https://eyebyte.tv/sitemap.xml.
5. Test each page and each media URL on current Chrome, Safari, Firefox and Edge, including a real iPhone and Android device.
6. Run PageSpeed Insights on the deployed homepage and service pages. Google's recommended good Core Web Vitals are LCP ≤ 2.5 s, INP < 200 ms and CLS < 0.1; field data requires real visitor data.
7. Submit a test enquiry and confirm delivery to eyebyte@gmail.com; test the visit counter increment on the live domain.
8. Confirm the server returns video/mp4 and supports byte-range requests for the local video assets.

Compatibility goal: current evergreen browsers and current iOS/Android browsers, with graceful fallbacks where supported APIs are unavailable. No website can be guaranteed error-free on every historical browser, device, network or browser extension.
