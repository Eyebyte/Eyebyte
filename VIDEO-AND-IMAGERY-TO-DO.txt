EYEBYTE WEBSITE — VIDEO & IMAGERY PRODUCTION TO-DO LIST
======================================================

PURPOSE
Create the custom visual assets for the Eyebyte website. This document is the production handoff: exact filenames, dimensions, formats, codecs, bitrates and visual notes. Save files in the named folders and use the exact filenames so the website can find them.

GENERAL EXPORT RULES
--------------------
VIDEO MASTER FORMAT
[ ] Container: MP4
[ ] Video codec: H.264 / AVC, High Profile
[ ] Pixel format: 8-bit 4:2:0, yuv420p
[ ] Colour: Rec.709 SDR (not HDR); 8-bit
[ ] Frame rate: 25 fps preferred; 30 fps acceptable. Keep each loop consistent.
[ ] Bitrate control: VBR, 2-pass where available
[ ] 1920x1080 videos: target 6–8 Mbps; maximum peak around 10 Mbps
[ ] 1440x1800 hero / 1440x1200 hardware: target 8–10 Mbps; peak around 12 Mbps
[ ] 1080x1080 square video: target 6–8 Mbps
[ ] No audio track; audio is unnecessary for these muted autoplay loops
[ ] Enable MP4 Fast Start (move the moov atom to the start; FFmpeg option: -movflags +faststart)
[ ] Loops should be 8–12 seconds where possible. Match first/last frames or use a clean motion loop point.
[ ] Do not add black letterboxing, embedded web borders, labels or captions; site typography and frames sit on top.
[ ] Keep important content inside a central safe zone: leave roughly 8–10% free around edges for responsive crops.
[ ] Make movement readable at small sizes. Avoid fast flashes, strobing, tiny text or excessively noisy details.
[ ] Keep each video concise and optimized. Aim for about 5–12 MB per loop when achievable without visible damage.

STILL IMAGE MASTER FORMAT
[ ] Preferred: WebP, sRGB, 8-bit, quality 80–85
[ ] For project rollover images: target 200–500 KB; aim to stay below 700 KB
[ ] For poster frames: WebP quality around 82; target 150–350 KB
[ ] No alpha needed for photography/backplates. Use transparency only for logos.
[ ] Do not bake UI borders or text into backgrounds. Keep enough dark space where copy will overlay.
[ ] Photos should be real Eyebyte event/stage/hardware photography where possible, not generic stock.

EXPORT COMMAND EXAMPLE (OPTIONAL)
---------------------------------
FFmpeg example for a silent H.264 web loop:
ffmpeg -i input.mov -an -c:v libx264 -profile:v high -pix_fmt yuv420p -r 25 -b:v 7000k -maxrate 9000k -bufsize 14000k -movflags +faststart output.mp4

Adjust -b:v / -maxrate based on the target specified for each asset. This is an example, not a universal preset.
